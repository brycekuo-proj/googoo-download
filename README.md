# 咕咕學堂

國小二年級 國語・數學・英語 練習（康軒國語、康軒數學、何嘉仁 WOW! STORY）。

## 網頁版（iPhone、iPad、Android、電腦都能用）

https://brycekuo-proj.github.io/googoo-download/?openExternalBrowser=1

- 不用安裝，用瀏覽器打開就能用；在 LINE 裡點開會自動改用 Safari／Chrome。
- iPhone、iPad：在 Safari 按「分享」→「加入主畫面」，就會像 App 一樣有圖示。
- 進度存在這台裝置的瀏覽器裡；清除瀏覽器資料會不見。
